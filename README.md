# 🏛️ Projeto de Interação Humano-Computador (IHC) - TCDF

Bem-vindo ao repositório do projeto da disciplina de **Interação Humano-Computador (IHC)** do curso de Engenharia de Software da Universidade de Brasília (FGA - UnB). 

Este repositório concentra todos os artefatos, pesquisas e documentos desenvolvidos ao longo do semestre letivo. O objeto de estudo escolhido para a aplicação prática do ciclo de vida completo de IHC é o portal institucional do **[Tribunal de Contas do Distrito Federal (TCDF)](https://www2.tc.df.gov.br/)**.

---

## 🎯 Sobre o Projeto

O portal do TCDF atua como uma ferramenta fundamental de transparência, controle externo e prestação de serviços para a sociedade do Distrito Federal. Devido à diversidade de seu público — que vai desde cidadãos leigos buscando informações de transparência até gestores públicos e advogados —, o site apresenta um alto nível de complexidade e densidade de informações.

O objetivo deste projeto semestral é **analisar, avaliar e reprojetar** a interface do portal, aplicando métodos científicos e práticos de IHC para garantir que o sistema atenda aos mais altos critérios de **usabilidade, acessibilidade e comunicabilidade**.
