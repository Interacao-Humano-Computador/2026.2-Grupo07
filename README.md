# 📝 Projeto de Interação Humano-Computador (IHC) — PCI Concursos

Bem-vindo ao repositório oficial do projeto da disciplina de **Interação Humano-Computador (IHC)** do curso de Engenharia de Software da Universidade de Brasília (FCTE/FGA - UnB), semestre letivo 2026.

Este repositório reúne todos os artefatos, pesquisas empíricas, análises de engenharia de usabilidade e documentos desenvolvidos ao longo do semestre. O objeto de estudo selecionado para a aplicação prática do ciclo de vida de IHC é o portal nacional **[PCI Concursos](https://www.pciconcursos.com.br/)**.

🌐 **Acesse a documentação completa publicada:** [https://Interacao-Humano-Computador.github.io/2026.2-Grupo07/](https://Interacao-Humano-Computador.github.io/2026.2-Grupo07/)

---

## 🎯 Sobre o Projeto

O portal **PCI Concursos** é uma das maiores referências no Brasil para candidatos e estudantes em busca de editais, notícias sobre certames, folhas de resposta, videoaulas e provas anteriores. Contudo, devido à massiva quantidade de informações, tabelas condensadas e excesso de anúncios publicitários intercalados no conteúdo, a interface atual apresenta atritos ergonômicos e riscos de desorientação.

O objetivo do projeto é **analisar, avaliar e reprojetar** a interface do portal, adotando o ciclo de vida da Engenharia de Usabilidade de **Deborah Mayhew (1999)** e as diretrizes clássicas de IHC (Barbosa et al., 2021) para aprimorar significativamente a **usabilidade, comunicabilidade, acessibilidade digital e a eficiência das tarefas** de busca e estudo.

## 🛠️ Tecnologias e Ferramentas

Para a documentação, organização e apresentação dos artefatos ao longo do semestre:

* **MkDocs com tema Material:** Geração de documentação estática responsiva, estilização visual com modo claro/escuro, diagramas Mermaid interativos com controles de zoom e navegação estruturada.
* **GitHub & GitHub Pages:** Versionamento em branches por funcionalidade/correção, revisão por Pull Requests e deploy contínuo em produção.
* **YouTube:** Hospedagem das gravações e entrevistas empíricas com usuários e vídeos de apresentação das etapas.
