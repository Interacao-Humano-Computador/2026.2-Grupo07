# Avaliações dos Protótipos

## 1. Introdução

Este artefato atende ao item 9 do Projeto Final (SALES, 2026): as avaliações dos protótipos, com os entrevistadores, o número de participantes e os integrantes do grupo que participaram de cada avaliação. As avaliações foram planejadas com o framework DECIDE, precedidas de teste-piloto (com dados descartados) e conduzidas com usuários do [Perfil do Usuário](../analise-de-requisitos/perfil-de-usuario.md), com o termo de consentimento previsto nos [Aspectos Éticos](../analise-de-requisitos/aspectos-eticos.md) (BARBOSA et al., 2021).
