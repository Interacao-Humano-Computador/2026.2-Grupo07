# Projeto: PCI Concursos

Bem-vindo à documentação oficial do projeto da disciplina de **Interação Humano-Computador (IHC)**, ministrada na Faculdade UnB Gama (FGA) no semestre letivo 2026.

Este projeto tem como objetivo a análise rigorosa, avaliação heurística, levantamento de requisitos com usuários reais e reprojeto da interface do portal **PCI Concursos** ([pciconcursos.com.br](https://www.pciconcursos.com.br/)), buscando aprimorar substancialmente a usabilidade, acessibilidade digital e a experiência do usuário (UX) de uma das plataformas de utilidade pública mais acessadas do Brasil.
