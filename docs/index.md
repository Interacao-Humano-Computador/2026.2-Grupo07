# Projeto: PCI Concursos

Bem-vindo à documentação oficial do projeto da disciplina de **Interação Humano-Computador (IHC)**, ministrada na Faculdade UnB Gama (FCTE/FGA) no semestre letivo 2026.

Este projeto tem como objetivo a análise rigorosa, avaliação empírica e heurística, levantamento de requisitos com usuários reais e o reprojeto de usabilidade da interface do portal **PCI Concursos** ([pciconcursos.com.br](https://www.pciconcursos.com.br/)), buscando aprimorar substancialmente a experiência do usuário (UX), a acessibilidade digital e a eficiência de busca em uma das plataformas de certames mais acessadas do Brasil.
