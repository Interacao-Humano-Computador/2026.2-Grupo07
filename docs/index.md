# Projeto: Tribunal de Contas do Distrito Federal (TCDF)

Bem-vindo à documentação oficial do projeto da disciplina de Interação Humano-Computador (FGA-UnB), semestre 2026.

Este projeto tem como foco a análise, avaliação heurística e reprojeto da interface do **Portal Institucional do TCDF**, visando melhorar a usabilidade e a acessibilidade dos serviços públicos prestados ao cidadão.

Para navegar pela documentação da Etapa 1 (Planejamento), utilize o menu lateral ou superior.
